# Calcify 🧮

**Calcify** is a modern, lightweight, and intuitive calculator application designed to provide essential mathematical operations with a sleek user interface. It is built with HTML, CSS, and JavaScript, making it perfect for anyone looking for a simple yet powerful calculator.

---

## Features ✨

- **Standard Calculator Mode**: Perform basic arithmetic operations like addition, subtraction, multiplication, and division.
- **Percentage Functionality**: Easily calculate percentages with a single button click.
- **Responsive Design**: Optimized for all devices, from desktops to mobile phones.
- **Dark Theme**: Sleek and modern dark-themed interface for comfortable usage.
- **Expandable Functionality**: Includes a `Converter` tab for future implementation of conversion features.

## Installation 🛠️

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/brucekariuki/Calcify.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Calcify
   ```

3. Open the `Calcify.html` file in your browser:
   ```bash
   open Calcify.html
   ```

## Usage 📖

### Standard Mode:
1. Enter numbers using the keypad.
2. Use the operator buttons (`+`, `-`, `×`, `÷`) to perform calculations.
3. Click `%` to calculate percentages.
4. Press `=` to get the result.
5. Use `C` to clear the screen or `⌫` to backspace.

### Converter Mode:
- **Coming Soon**: A dedicated tab for unit conversions (e.g., length, weight, temperature).
